# HemoRush

Jogo 3D (vista de cima) sobre compatibilidade sanguínea ABO/Rh, com tema da Fundação Hemominas.
Você é a Ada, farmacêutica bioquímica da prova cruzada: pega bolsas de concentrado de hemácias no estoque e entrega aos transportadores, respeitando as regras reais de compatibilidade.

**Projeto privado em desenvolvimento.**

## Como rodar

Abra o `index.html` no navegador (precisa de internet para carregar o Three.js e a fonte). No celular, jogue na horizontal.

## Estrutura

Tudo em um único arquivo, `index.html` (HTML, CSS e JS). Detalhes para quem for mexer no código estão no [CLAUDE.md](CLAUDE.md).
