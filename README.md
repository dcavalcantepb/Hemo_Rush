# HemoRush

Jogo 3D (vista de cima) sobre compatibilidade sanguínea ABO/Rh, com tema da Fundação Hemominas.
Você é a Ada, farmacêutica bioquímica da prova cruzada: pega bolsas de concentrado de hemácias no estoque e entrega aos transportadores, respeitando as regras reais de compatibilidade.

**Projeto em desenvolvimento.**

## Como rodar

Abra o `index.html` no navegador, com a pasta `assets/` ao lado (precisa de internet para carregar o Three.js e a fonte). No celular, jogue na horizontal.

## Estrutura

- `index.html`: todo o código (HTML, CSS e JS).
- `assets/`: artes em WebP (Ada e uma por nível de dificuldade).
- [CLAUDE.md](CLAUDE.md): guia para quem for mexer no código.
